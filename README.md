# Тамга — сайт ресторана

Одностраничный сайт семейного ресторана этнической кухни «Тамга» (г. Нальчик, ул. Тлостанова, 49): чистый HTML, CSS и JavaScript без сборщиков и зависимостей.

Дизайн — светлая пергаментная гамма под фирменный стиль ресторана (кремовые стены с тамгами, солома, светлое дерево), с орнаментными завитками из печатного меню и логотипом-монограммой.

## Разделы сайта

- **Герой** — фотофон, слоган «Род. Память. Вкус.», кнопки бронирования и меню
- **О нас** — «Вкус не придуман — он унаследован», локальные продукты, фотокарточки
- **Меню** — реальное меню ресторана целиком, 9 вкладок: завтраки, закуски и салаты, супы, основные блюда, мангал, из печи, паста и гарниры, десерты, напитки. Блюда с фотографиями — карточками, остальное — списком в стиле печатного меню
- **Галерея** — 12 фотографий с лайтбоксом (полноэкранный просмотр, листание)
- **Бронирование** — форма заявки с клиентской валидацией
- **Контакты** — реальные: адрес, часы работы (9:00–23:00, завтраки до 16:00), телефон +7 (928) 710-73-73, летний сад при отеле Altum

Фотографии блюд — профессиональная съёмка ресторана (автор: Алим Джаппуев), оптимизированы для веба и лежат в `img/`.

## Запуск

Сборка не требуется — просто откройте `index.html` в браузере, либо запустите локальный сервер:

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

## Структура

```
index.html      — разметка всех секций и полное меню
css/style.css   — стили, светлая тема, орнаменты, адаптив (900px и 720px)
js/main.js      — мобильное меню, вкладки меню, лайтбокс галереи, валидация формы
img/            — фотографии (hero, gallery-NN, dish-*, about-*)
```

## Что осталось доделать

- **Фото интерьера**: сейчас герой и галерея — из фото блюд; когда появятся интерьерные фото файлами или ссылкой, добавить их в галерею и герой
- **Отправка формы**: заявка подтверждается только на странице; подключите бэкенд или сервис форм в `js/main.js`
- Цены актуальны на меню от 29 июня — при изменении обновить в `index.html`
