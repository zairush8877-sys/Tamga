# Тамга — сайт ресторана

Одностраничный сайт ресторана восточной кухни «Тамга»: чистый HTML, CSS и JavaScript без сборщиков и зависимостей.

## Разделы сайта

- **Герой** — заглавный экран с фотофоном, кнопки бронирования и перехода к меню
- **О нас** — история ресторана, ключевые цифры и фотокарточки
- **Меню** — пять разделов с переключением вкладок (завтраки, закуски и салаты, супы, мангал и горячее, десерты); карточки блюд с фотографиями
- **Галерея** — 12 фотографий с лайтбоксом (клик — полноэкранный просмотр, листание стрелками и с клавиатуры)
- **Бронирование** — форма заявки с клиентской валидацией
- **Контакты** — адрес, часы работы, телефон

Фотографии блюд — профессиональная съёмка ресторана (автор: Алим Джаппуев), оптимизированы для веба и лежат в `img/`.

## Запуск

Сборка не требуется — просто откройте `index.html` в браузере, либо запустите локальный сервер:

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

## Структура

```
index.html      — разметка всех секций
css/style.css   — стили и адаптив (брейкпоинты 900px и 720px)
js/main.js      — мобильное меню, вкладки меню, лайтбокс галереи, валидация формы
img/            — фотографии (hero, gallery-NN, dish-*, about-*)
```

## Что заменить под реальный ресторан

- Телефон, адрес, e-mail и часы работы в `index.html` (секции «Контакты», шапка)
- Цены и составы блюд в секции меню — сейчас указаны ориентировочные
- Отправку формы: сейчас заявка подтверждается только на странице; подключите свой бэкенд или сервис форм в `js/main.js`
