# Тамга — сайт ресторана

Одностраничный сайт ресторана восточной кухни «Тамга»: чистый HTML, CSS и JavaScript без сборщиков и зависимостей.

## Разделы сайта

- **Герой** — заглавный экран с кнопками бронирования и перехода к меню
- **О нас** — история ресторана и ключевые цифры
- **Меню** — четыре раздела с переключением вкладок (горячее, закуски, мангал, десерты)
- **Галерея** — сетка фотографий (сейчас — цветные заглушки)
- **Бронирование** — форма заявки с клиентской валидацией
- **Контакты** — адрес, часы работы, телефон

## Запуск

Сборка не требуется — просто откройте `index.html` в браузере, либо запустите локальный сервер:

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

## Структура

```
index.html      — разметка всех секций
css/style.css   — стили и адаптив (брейкпоинты 900px и 720px)
js/main.js      — мобильное меню, вкладки меню, валидация формы
```

## Что заменить под реальный ресторан

- Телефон, адрес, e-mail и часы работы в `index.html` (секции «Контакты», шапка)
- Заглушки галереи: в `css/style.css` замените градиенты `.gallery__item--N` на `background-image: url(...)`
- Отправку формы: сейчас заявка подтверждается только на странице; подключите свой бэкенд или сервис форм в `js/main.js`
