# Тамга — сайт ресторана

**Сайт:** https://zairush8877-sys.github.io/Tamga/ (готовится переезд на https://tamga-rest.ru)

Одностраничный сайт семейного ресторана этнической кухни «Тамга» (г. Нальчик, ул. Тлостанова, 49): чистый HTML, CSS и JavaScript без сборщиков и зависимостей.

Дизайн — светлая пергаментная гамма под фирменный стиль ресторана (кремовые стены с тамгами, солома, светлое дерево), с орнаментными завитками из печатного меню и логотипом-монограммой.

## Разделы сайта

Сайт построен как «путь вглубь»: прокрутка ведёт посетителя сквозь закреплённые сцены-переходы (живой зал → горы → очаг → меню → стена рода → ночное бронирование). Движок сцен — `js/depth.js`: прогресс каждой сцены пишется в CSS-переменную `--p`, все движения слоёв заданы в CSS. Фоновые видео — кинемаграфы, сгенерированные из реальных фотографий ресторана (Higgsfield, Seedance 2.0); панорамы гор — Nano Banana Pro.

- **Герой** — видео-кинемаграф зала на весь экран, слоган «Род. Память. Вкус.», кнопки бронирования и меню; при прокрутке камера «влетает» внутрь
- **Горы** — панорама Эльбруса в пергаментной дымке, слова «Род. Память. Вкус.» проявляются по мере погружения
- **Очаг** — живой огонь мангала в арке, летящие угли (canvas)
- **Стена рода** — кинемаграф стены с тамгами и приглашение к брони
- **О нас** — «Вкус не придуман — он унаследован», локальные продукты, фотокарточки
- **Меню** — реальное меню ресторана целиком, 9 вкладок: завтраки, закуски и салаты, супы, основные блюда, мангал, из печи, паста и гарниры, десерты, напитки. Блюда с фотографиями — карточками с каруселью из 2–3 ракурсов (стрелки и свайп), остальное — списком в стиле печатного меню. Данные меню лежат в `data/menu.js` и рисуются скриптом `js/menu.js`
- **Галерея** — 12 фотографий (интерьер, фирменная керамика, блюда) с лайтбоксом
- **Бронирование** — форма заявки с клиентской валидацией
- **Контакты** — реальные: адрес, часы работы (9:00–23:00, завтраки до 16:00), телефон +7 (928) 710-73-73, летний сад при отеле Altum

Фотографии блюд — профессиональная съёмка ресторана (автор: Алим Джаппуев); фото интерьера и фирменного стиля — от заказчика. Все изображения оптимизированы для веба и лежат в `img/`.

## Публикация

Сайт статический, собирать нечего — публикуется как есть из корня репозитория.

- **GitHub Pages** (основной адрес): workflow `.github/workflows/pages.yml` при push
  переносит файлы в ветку `gh-pages` и запрашивает сборку через API. В настройках
  репозитория: Settings → Pages → Source: Deploy from a branch → `gh-pages` / `(root)`.
  Свой домен — файл `CNAME` в корне репозитория плюс DNS-записи у регистратора.
- **Netlify** (`netlify.toml`): выкладка приостановлена — на бесплатном тарифе
  у команды закончились минуты сборки. Старая версия остаётся доступной по
  https://tamga-rest.netlify.app до конца расчётного периода.

## Телеграм-бот для правки меню

Владелец меняет цены и фотографии прямо из телеграма: «цена сырники 420»,
«скрыть …», «показать …» или фотография с подписью-названием блюда. Бот правит
`data/menu.js` (фото кладёт в `img/tg/`), коммитит и публикует сайт.

Сервера у сайта нет, поэтому бот живёт в GitHub Actions: workflow
`.github/workflows/tgbot.yml` раз в несколько минут запускает
`scripts/tgbot-poll.mjs`, который забирает новые сообщения у Telegram
(long polling), вносит правки и вызывает публикацию. Правка доезжает до
сайта за несколько минут; для публичных репозиториев Actions бесплатны.

Подключение (один раз):

1. В Telegram у **@BotFather**: `/newbot` → получить токен.
2. GitHub → Settings → Secrets and variables → Actions → **New repository secret**:
   `TG_BOT_TOKEN` = токен от BotFather, `TG_ADMINS` = пока любое число.
3. Написать боту `/start` и подождать несколько минут — он ответит вашим chat id.
4. Вписать этот id в секрет `TG_ADMINS` (несколько владельцев — через запятую).

Мгновенный вариант (когда снова заработает выкладка на Netlify):
функция `netlify/functions/tgbot.mjs` — тот же бот, но вебхуком, без задержки.
Ему нужны переменные `TG_BOT_TOKEN`, `TG_SECRET`, `TG_ADMINS`, `GH_TOKEN`
и вызов `setWebhook` с адресом функции.

## Запуск локально

Сборка не требуется — просто откройте `index.html` в браузере, либо запустите локальный сервер:

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

## Анимации

- Появление блоков при прокрутке (IntersectionObserver) с каскадом внутри сеток
- Ken Burns на фото героя + параллакс фона и текста при прокрутке
- Тайные родовые тамги на главном экране: знаки, перерисованные с рельефной стены зала, едва различимо проявляются из глубины и растворяются, как тиснение; курсор — «свет факела», рядом с которым знак разгорается тёплым золотом (`js/tamgi.js`)
- Счётчики в блоке «О нас» набегают до значения при появлении
- Каскадное появление карточек при переключении вкладок меню
- Карусель ракурсов в карточках блюд: стрелки, точки-индикаторы, свайп на телефоне; дополнительные кадры подгружаются только при листании
- Прогресс-бар прокрутки, кнопка «наверх», подсветка текущего раздела в навигации
- Ховеры: подъём карточек, зум фото, лупа на галерее, блик на кнопках
- Орнамент у заголовков прорисовывается, поля формы «вздрагивают» при ошибке

Все анимации отключаются при системной настройке «уменьшить движение» (`prefers-reduced-motion`).

## Структура

```
index.html      — разметка всех секций и сцен погружения, OG-теги и JSON-LD
media/          — видео-кинемаграфы сцен (mp4, сгенерированы из реальных фото)
js/depth.js     — движок сцен погружения (--p) и канвас углей
data/menu.js    — данные меню: разделы, блюда, цены, фото (правит телеграм-бот)
css/style.css   — стили, светлая тема, орнаменты, анимации, адаптив (900px и 720px)
js/menu.js      — рендер меню из data/menu.js и карусель фото в карточках
js/main.js      — мобильное меню, вкладки, лайтбокс, валидация формы, scroll-анимации
js/tamgi.js     — векторы 16 родовых тамг и физика их движения на canvas
scripts/tgbot-poll.mjs — телеграм-бот (опрос из GitHub Actions)
netlify/functions/tgbot.mjs — он же вебхуком, если вернётся Netlify
img/            — фотографии (hero, gallery-NN, dish-* с ракурсами -2/-3, about-*)
```

## Что осталось доделать

- **Отправка формы**: заявка подтверждается только на странице; подключите бэкенд или сервис форм в `js/main.js`
- **Телеграм-бот**: код готов, нужно один раз задать секреты `TG_BOT_TOKEN` и `TG_ADMINS` (см. раздел выше)
- Цены актуальны на меню от 29 июня — дальше правятся ботом или в `data/menu.js`
